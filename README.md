# Dokumentasi Kegiatan Workshop

## 1. Prompt Engineering
Prompt Engineering merupakan cara menyusun instruksi agar AI dapat memberikan hasil yang tepat, relevan, dan sesuai kebutuhan.
Prompt adalah instruksi atau masukan yang diberikan kepada AI untuk memperoleh hasil tertentu.

### Struktur Prompt yang Baik
Terdapat empat elemen utama dalam menyusun prompt:
- **Role:** Menentukan peran yang harus dijalankan AI.
- **Task:** Menentukan tugas yang harus dikerjakan.
- **Context:** Memberikan informasi dan latar belakang mengenai tugas.
- **Format:** Menentukan bentuk hasil yang diinginkan.

### Keuntungan Prompt Engineering
1. Meningkatkan performa AI model.
2. Mengurangi bias dan respons yang ofensif.
3. Meningkatkan kontrol dan prediktabilitas.
4. Memberikan pengalaman yang lebih baik.

## 2. Pengenalan Git dan GitHub
### Pengertian Git
Git merupakan Version Control System yang digunakan untuk melacak dan mengelola perubahan pada file. Git mencatat siapa yang melakukan perubahan, kapan perubahan dilakukan, dan apa saja yang berubah.
Git diciptakan oleh Linus Torvalds pada tahun 2005.

### Pengertian GitHub
GitHub merupakan platform berbasis web yang digunakan untuk menyimpan repository Git secara online serta mendukung kolaborasi antar pengguna.

### Perbedaan Git dan GitHub
- **Git:** Sistem untuk mengelola riwayat perubahan proyek secara lokal.
- **GitHub:** Platform online untuk menyimpan repository Git dan mendukung kolaborasi.

## 3. Git Workflow
Git memiliki tiga bagian utama dalam alur kerjanya:
1. **Working Directory:** Tempat pengguna mengerjakan dan mengubah file proyek.
2. **Staging Area:** Tempat menyimpan informasi perubahan yang akan dimasukkan ke commit berikutnya.
3. **Git Repository:** Tempat Git menyimpan informasi dan riwayat perubahan proyek.

### Perintah Dasar Git
| Perintah | Fungsi |
| `git init` | Membuat repository Git baru |
| `git add .` | Memasukkan perubahan ke staging area |
| `git commit -m "message"` | Menyimpan perubahan sebagai commit |
| `git remote add` | Menghubungkan repository lokal dengan remote |
| `git push` | Mengirim perubahan ke repository remote |
| `git pull` | Mengambil dan menggabungkan perubahan dari remote |

### Perintah Git dan GitHub
- `git push origin main`: Mengirim perubahan ke branch main pada remote origin.
- `git pull origin main`: Mengambil dan menggabungkan perubahan dari remote main.

## 4. Git Setup dan VS Code
Sebelum menggunakan Git, diperlukan instalasi dan konfigurasi terlebih dahulu.
Beberapa perintah untuk memeriksa dan mengatur Git:
```
git --version

git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

Untuk memeriksa konfigurasi:
```
git config --global --list
```

VS Code juga dapat digunakan sebagai editor kode dan menyediakan terminal untuk menjalankan perintah Git.

## 5. Repository dan SSH Key
Repository dapat dibuat secara lokal menggunakan:
```
git init
```

Sedangkan untuk menyalin repository yang sudah tersedia di GitHub:
```
git clone "url"
```

Workshop juga memperkenalkan SSH Key sebagai metode autentikasi untuk menghubungkan komputer dengan GitHub.
SSH menggunakan dua jenis kunci:
- **Private Key:** Kunci pribadi yang harus dijaga kerahasiaannya.
- **Public Key:** Kunci publik yang dapat ditambahkan ke pengaturan GitHub.
